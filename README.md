## 🚂 Overview

> **IndianRail.gov** is a fully responsive, feature-rich **IRCTC-inspired Railway Reservation Portal** — a frontend clone of the official Indian Railways booking system. It includes a complete 3-step ticket booking flow, PNR status checker, live train schedule, 12 railway services, bilingual UI (Hindi + English), multi-payment gateway, user auth, and government-style notices — all built with pure HTML, CSS & JavaScript. No frameworks. No backend.

## ✨ Features

### 🎫 Ticket Booking System (3-Step Flow)
- 🔍 **Step 1 — Journey Details** — From/To Station, Date, Class (SL / 3A / 2A / 1A / CC / EC), Quota (General / Ladies / Senior / Tatkal / Defence / Divyaang), No. of Passengers
- 🚆 **Train Results** — Live search results with Train No., Name, Route, Distance, Seat Availability, Price & Days of operation
- 👤 **Step 2 — Passenger Info** — Contact Mobile & Email with form validation
- 💰 **Step 3 — Payment** — Full multi-payment gateway UI:
  - 📱 UPI / BHIM (GPay, PhonePe, Paytm, BHIM)
  - 💳 Debit / Credit Card (Name, Number, Expiry, CVV)
  - 🏦 Net Banking (SBI, HDFC, ICICI, Axis, PNB & more)
  - 👛 Wallets (Paytm, Amazon Pay, Mobikwik, FreeCharge, Ola Money)
- 🧾 **Fare Summary** — Base Fare + Reservation Charge + Superfast Charge + GST = Total

### 📋 PNR Status Checker
- 🔢 **10-digit PNR Input** — Enter PNR to get real-time status
- ✅ **Live Result** — Train name, Route, Date, Class, Departure, Arrival, Chart Status
- 👥 **Passenger Table** — Booking Status, Current Status, Coach & Berth for each passenger
- 📖 **Status Codes Guide** — CNF, WL, RAC, CAN, PQWL explained

### 🗓️ Train Schedule & Timetable
- 🔍 **Search Trains** — Find trains by route or name
- 📊 **Schedule Table** — Train No., Name, From, Departure, To, Arrival, Days, Live Status
- 🔴 **Live Running Status** — Real-time train position display

### 🛎️ 12 Railway Services
- 🎫 Ticket Booking — Regular, Tatkal, Premium Tatkal
- 📋 PNR Status — Live reservation updates
- 📡 Train Tracking — GPS-based live location
- 🍱 e-Catering — Food delivery at your seat
- ❌ Cancellation — Easy online cancellation & refund
- 🏨 Retiring Room — Station retiring room booking
- 📦 Luggage / Parcel & Cargo — Advance registration
- ♿ Divyaang Services — Special concessions & facilities
- 🎓 Student Concession — Special student rates
- 👴 Senior Citizen — 40% concession on fares
- 🗺️ Tourist Packages — Special rail tour packages
- 🎫 Monthly Pass / Season Ticket — Daily commuter pass

### 📰 Latest Notices Board
- 🔴 **Urgent** — Train delay alerts (e.g. 12302 Howrah Rajdhani delay notice)
- 🔵 **Info** — Tatkal booking updates, festival season notices
- 🟢 **New** — Vande Bharat Express new schedule
- 🟡 **Info** — Senior citizen concession reinstatement notices

### 🔐 Auth System (Login / Register)
- 🔑 **Sign In** — Mobile / Email / User ID + Password, Remember Me, Forgot Password flow

- ✅ **Modals** — Success states for Login, Register & Password Reset

## ⚙️ How It Works

```javascript
1. User lands on hero with animated counter stats & search form
2. Selects journey details → searches trains → results appear
3. Selects train → fills passenger info → proceeds to payment
4. Fare summary calculates: Base + Reservation + Superfast + GST
5. Payment method selected → UPI / Card / Net Banking / Wallet UI shown
6. PNR Status section takes 10-digit PNR → shows passenger & coach details
7. Train Schedule search filters timetable table by route/train
8. Login / Register modals handle auth flow with Hindi+English labels
9. Contact form collects query with subject dropdown & message
10. Notice board displays government-style urgent & info alerts
```
